Integração com o sistema e os portais

O site não tem cadastro paralelo: ele lê o XML (feed) que o Jetimob já gera para os portais. O corretor cadastra uma vez; site e portais mostram o mesmo imóvel, com o mesmo código.

    Como funciona no site real
    
    
    1. Cadastro no sistemaO corretor cadastra ou altera o imóvel no Jetimob, como já faz hoje.
    2. XML atualizadoO sistema gera o arquivo com todos os imóveis ativos, fotos e preços.
    3. Importação automáticaO site lê o arquivo a cada hora, cria as páginas e atualiza busca, bairros e destaques.
    4. Saiu do sistema, saiu do siteImóvel vendido ou alugado deixa de aparecer na próxima leitura.
